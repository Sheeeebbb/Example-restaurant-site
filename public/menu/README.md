# Menu photography

Dish images go here, using the filenames referenced by `src/lib/data/menu.ts`
(`margherita.jpg`, `burrata.jpg`, and so on).

Until real photography lands, cards render a warm gradient placeholder, marked
`aria-hidden` because a decorative stand-in has no meaning to describe.

Guidance when adding images:

- 4:3, at least 800px wide.
- Warm, natural light. The surroundings stay neutral; the food supplies the colour.
- Write real `alt` text in `menu.ts` describing the dish, not the photograph.
